## Zelfstandig Python leren
Er zijn veel verschillende manier om jezelf te leren programmeren in Python. In mijn tijd, in de jaren B.C. (Before Chat), deden we dat nog met websites... Tegenwoordig wil je misschien gewoon 1 op 1 met ChatGPT aan de slag. Maar, voor degene die toch de websites willen, hier heb ik een lijstje van sites die mij destijds hebben geholpen:
- [W3schools](https://www.w3schools.com/python/)
- [GeeksForGeeks](https://www.geeksforgeeks.org/python/python-programming-language-tutorial/)
- [DataCamp (betaald)](https://www.datacamp.com/courses/intro-to-python-for-data-science)
